# Module 1: Password Security with John the Ripper

## Overview
This module introduces John the Ripper (JTR) and Johnny, a graphical interface for John the Ripper, as password-security auditing tools.

## Objectives
- Understand the purpose of John the Ripper.
- Explore the Johnny graphical interface.
- Learn about password hashes and password security.
- Understand the importance of strong passwords.

## Tools
- John the Ripper
- Johnny GUI
- Windows PC

## Lab Environment
- Operating System: Windows
- Project: NetworkWalks Week 3 – Project Module 1

## Concepts Covered
- Password security
- Password hashes
- Password auditing
- Password strength
- Security implications of weak passwords

## Screenshots and Observations

Screenshots and observations from the lab will be added here as the project progresses.

## Lessons Learned
This module introduces password-auditing concepts and demonstrates why password strength is an important aspect of cybersecurity.

## Conclusion
The exercise provides an introduction to password security and the tools used by cybersecurity professionals to evaluate password protection in authorized environments.
