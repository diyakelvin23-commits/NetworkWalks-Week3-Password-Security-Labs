# Module 1: Password Security with John the Ripper

## Overview

This project module explores password security and password-auditing concepts using John the Ripper (JTR) and Johnny, its graphical interface. The exercise forms part of the NetworkWalks Week 3 cybersecurity practical training.

## Objectives

- Understand the purpose of John the Ripper.
- Explore the Johnny graphical interface.
- Learn about password security and password hashes.
- Understand the importance of strong passwords.
- Gain familiarity with password-auditing tools.

## Tools Used

- John the Ripper (JTR)
- Johnny GUI
- Windows PC
